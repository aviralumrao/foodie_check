🐘 PostgreSQL Installation

Setting up your database for Foodie Check

⚠️

PostgreSQL Not Installed

Our checks show PostgreSQL is not installed on your system. No Windows service found, no installation directory, and psql command not available in PATH.

1 Choose Installation Method

Download & Install PostgreSQL 17

This is the recommended method for Windows users.

  1. Visit the official PostgreSQL download page
  2. Download PostgreSQL 17 for Windows x64
  3. Run the installer (postgresql-17.x-windows-x64.exe)
  4. Follow the installation wizard
📥 Download PostgreSQL 17

⚠️ Important Settings During Installation:

  • ✓ Password: Set a password for the "postgres" user (remember this!)
  • ✓ Port: Keep default port 5432
  • ✓ Locale: Keep default (English, United States)
  • ✓ pgAdmin 4: Check this box (useful GUI tool)

Install via Winget (Command Line)

Open PowerShell as Administrator and run:

winget install PostgreSQL.PostgreSQL.17 --accept-source-agreements --accept-package-agreements

💡 Note: If User Account Control prompts appear during installation, approve them. The installer may show a configuration window where you set the postgres user password.

2 Verify Installation

After installation completes, close and reopen PowerShell, then run:

psql --version

✅ Expected output: psql (PostgreSQL) 17.x

If the command is not recognized, add PostgreSQL to your PATH manually:

$env:Path += ";C:\Program Files\PostgreSQL\17\bin"

3 Create the Database

Once PostgreSQL is installed, create the foodie_check database:

Connect to PostgreSQL

psql -U postgres

Enter the password you set during installation.

Create Database

Inside the psql prompt, run:

CREATE DATABASE foodie_check;

Verify It Was Created

\l

You should see foodie_check in the list.

Exit psql

\q

4 Next Steps

Once PostgreSQL is set up, you're ready to start all services!

📖 Continue with: Follow the instructions in START_ALL_SERVICES.md to launch the Go backend, Python OCR engine, and Next.js frontend.

Quick Connection String Reference

You'll need this when starting your services:

postgresql://postgres:YOUR_PASSWORD@localhost:5432/foodie_check

Replace YOUR_PASSWORD with the password you set during installation.

🔧 Troubleshooting

PostgreSQL Service Not Running

Check if the service is running:

Get-Service -Name postgresql*

If it's stopped, start it:

Start-Service postgresql-x64-17

Cannot Connect to Database

Ensure PostgreSQL is listening on localhost:5432 and your password is correct.

psql Command Not Found After Installation

Manually add to PATH or use the full path:

"C:\Program Files\PostgreSQL\17\bin\psql.exe" -U postgres
